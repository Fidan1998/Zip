# OLD ROCKER CAVID — Shiny Birthday Website

A retro early-2000s-inspired birthday tribute site, built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — glittery welcome / entrance screen
- `home.html` — birthday homepage
- `about.html` — story about Dad
- `gallery.html` — photo album placeholders
- `memories.html` — family memories
- `music.html` — soundtrack / favourite songs
- `style.css` — retro gold, blue, sparkles, frames and animations
- `script.js` — tiny decorative effect

## Preview
Open `index.html` in a browser, then click the entrance button.

## Personalize it before publishing
- Replace photo placeholders with your own family photos.
- Add real stories and memories in `about.html` and `memories.html`.
- Add his favourite artists and songs in `music.html`.
- Adjust the name or wording if needed.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a repository, e.g. `oldrockercavid`.
3. Upload the contents of this folder into the repository root.
4. Go to Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Once you own the domain, add `oldrockercavid.com` in the GitHub Pages custom domain setting and configure DNS according to GitHub's current documentation: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site

The site itself can be hosted for free. Domain registration is a separate annual cost.
